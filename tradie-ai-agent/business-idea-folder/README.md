# Business Idea Folder — Tradie Connect

Pitch materials for selling Tradie Connect to new customers (Australian trade businesses, 1–10+ tradies).

| File | What it is | Use it for |
|------|-----------|------------|
| `index.html` | Full visual pitch page (published as an artifact) | Send the link, or present it on screen |
| `pitch.md` | The pitch in plain text: problem, product, value, pricing, objections | Prep before a meeting, copy into emails |
| `diagrams.md` | Mermaid diagrams: system overview, booking sequence, tradie day | Paste into slides, Notion, GitHub |
| `demo-script.md` | Step-by-step live demo you can run on a call | Running the demo with a prospect |
| `pilot-offer.md` | One-page 30-day pilot proposal | Closing the meeting |

Live pitch page: https://claude.ai/artifact/2axK2JsnUNBiM8BwnAmviK (private until you share it)

**Note on numbers:** running costs come from the repo's AWS cost model (README.md). Pricing tiers and ROI figures are suggestions/assumptions for discussion. Validate them before quoting.
